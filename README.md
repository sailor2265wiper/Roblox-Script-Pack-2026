XCutors is a convenient collection (or 'pack') that bundles several well-known Roblox script execution tools and a universal loader into a single, easy-to-use package for Windows.

The package itself is a legitimate application bundle. However, as with any software that interacts with other programs, you should always download from official sources and use your best judgment regarding security.

### Which executors are included?

The current collection includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader. Support for additional tools may be added in future updates.

### Do I need to install each executor separately?

No. The universal loader (xcutorsLoader) and the main XCutors launcher are designed to manage and switch between the included executors for you.

### Will this work on Mac or Linux?

No. XCutors and the included executors are developed specifically for the Windows operating system.

### What kind of scripts can I run?

You can run a wide variety of Lua scripts designed for Roblox customization. The effectiveness depends on the specific script and the executor's capabilities.

### How do I update the executors?

Run the XCutors launcher; it will check for and download updates for the bundled tools automatically when available. You can also check the GitHub Releases page.
